# Example: A Good Honest Recommendation

**Traveler**: Dallas to NYC, March 11–15, 2027, 1 traveler, carry-on, 4 hotel nights.  
**Status**: Fictional teaching example ONLY.

- Flight A: fictional base fare $218 + fictional carry-on fee $35 = **$253**.
- Hotel B: fictional stay rate $600 + fictional mandatory fees $210 = **$810**.
- Combined example cash total: **$1,063**.
- If assumed card earns 3 points per dollar, modeled points earned: **3,189** (assumes both purchases eligible at 3x).
- If user values points at 1.5¢, estimated earned-points economic value is **$47.84**. It is not a cash discount and is not guaranteed.

**Correct agent language:** “This is a synthetic test comparison. It shows the method but does not establish the lowest purchasable fare. For live recommendations, verify direct carrier or search offers, ensure one carry-on and hotel fees are included, and check checkout inventory before making a recommendation.”

**Wrong agent language:** “I found a real $1,063 trip that you can book right now.”

**Improvement opportunity:** Give a transparent comparison between live provider estimates and a confirmed final booking quote. Show 'not checked' for providers with no access rather than fabricating a comparison.
